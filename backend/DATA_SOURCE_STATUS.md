# 데이터 소스 상태

## 현재 상태: Mock 데이터 사용 중 ⚠️

### 확인 사항

1. **Service Key 설정**: ✅ 환경변수에 설정됨
   - `ADMINISTRATIVE_CODE_SERVICE_KEY`: 설정됨
   - `HIRA_SERVICE_KEY`: 설정됨
   - `HIRA_PRICING_SERVICE_KEY`: 설정됨

2. **실제 API 호출 시도**: ✅ 시도 중
   - 백엔드 로그에서 실제 API 호출 시도 확인
   - 엔드포인트: `https://apis.data.go.kr/B552584/AdministrativeCodeService/getAdministrativeCode`

3. **API 응답**: ❌ 실패 (500 에러)
   - 실제 API 호출 시 500 Internal Server Error 발생
   - 에러 메시지: "unexpected errors"
   - 원인: API 엔드포인트 또는 파라미터 불일치 가능성

4. **폴백 동작**: ✅ 정상 작동
   - API 호출 실패 시 자동으로 Mock 데이터 반환
   - 사용자는 정상적으로 데이터를 볼 수 있음

## 데이터 소스 구분

### Mock 데이터 (현재 사용 중)
- **시도 목록**: 하드코딩된 17개 시도 (서울, 부산, 대구 등)
- **시군구 목록**: 하드코딩된 주요 시군구 (서울 25개 구, 부산 16개 구 등)
- **병원 정보**: 샘플 데이터 (서울대학교병원, 세브란스병원 등)
- **비급여 가격**: 샘플 가격 데이터

### 실제 API 데이터 (목표)
- **행정안전부 법정동코드 API**: 실제 법정동 정보
- **건강보험심사평가원 병원정보 API**: 실제 병원 정보
- **건강보험심사평가원 비급여진료비 API**: 실제 비급여 가격 정보

## Mock 데이터를 사용하는 이유

1. **API 호출 실패**: 실제 API가 500 에러를 반환
2. **엔드포인트 불일치**: API 문서와 실제 엔드포인트가 다를 수 있음
3. **파라미터 형식**: API가 요구하는 파라미터 형식과 다를 수 있음
4. **서비스 키 문제**: 서비스 키가 만료되었거나 권한이 없을 수 있음

## 실제 API 연동을 위한 다음 단계

1. **API 문서 확인**
   - [행정안전부 법정동코드 API](https://www.data.go.kr/data/15001699/openapi.do)
   - 정확한 엔드포인트 URL 확인
   - 필수 파라미터 및 형식 확인

2. **서비스 키 확인**
   - 공공데이터포털에서 서비스 키 상태 확인
   - API 사용 승인 상태 확인
   - 서비스 키 만료일 확인

3. **API 테스트**
   - Postman 또는 curl로 직접 API 호출 테스트
   - 응답 형식 확인 (JSON/XML)
   - 에러 메시지 분석

4. **코드 수정**
   - 엔드포인트 URL 수정
   - 파라미터 형식 조정
   - 응답 파싱 로직 수정

## 현재 동작 방식

```
사용자 요청
  ↓
백엔드 API 호출 시도
  ↓
실제 API 호출 (500 에러)
  ↓
에러 감지
  ↓
Mock 데이터 반환 ✅
  ↓
프론트엔드에 전달
```

## 확인 방법

백엔드 콘솔 로그에서 다음 메시지를 확인:
- `✅ 실제 API 데이터 반환`: 실제 데이터 사용 중
- `⚠️ Mock 데이터를 반환합니다`: Mock 데이터 사용 중 (현재 상태)
