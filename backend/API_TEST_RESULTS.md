## 원인 분석

### 가능한 원인
1. **서비스 키 문제**
   - 서비스 키가 올바르지 않거나 만료됨
   - 서비스 키 인코딩 문제

2. **API 파라미터 문제**
   - 필수 파라미터 누락
   - 파라미터 형식 오류

3. **API 엔드포인트 문제**
   - 엔드포인트 URL이 변경됨
   - API 버전 불일치

4. **인증 문제** (401 에러)
   - 서비스 키 권한 부족
   - API 사용 승인 대기 중

## 다음 단계

### 1. 보안 그룹 포트 추가
AWS 콘솔에서 포트 3001을 열어야 외부 접근 가능:
- EC2 → 보안 그룹 → 인바운드 규칙 편집
- 포트 3001 (TCP) 추가

### 2. API 서비스 키 확인
- [공공데이터포털](https://www.data.go.kr)에서 서비스 키 상태 확인
- API 사용 승인 상태 확인
- 서비스 키 재발급 (필요 시)

### 3. API 문서 재확인
- 각 API의 최신 문서 확인
- 필수 파라미터 및 형식 확인
- 엔드포인트 URL 확인

### 4. Mock 데이터 활용
현재 Mock 데이터가 정상 작동하므로:
- 프론트엔드 개발 및 테스트 가능
- 실제 API 연동은 별도로 진행
