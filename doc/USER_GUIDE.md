# 사용자 가이드

## 병원 비급여 가격 비교 서비스 사용법

### 1. 병원 검색하기

#### 검색 조건 공유 링크 (URL)

- 주소에 다음 쿼리가 붙으면 **페이지를 열 때** 같은 조건으로 복원됩니다: `sido`(시도 코드), `sigungu`(시군구 코드), `q`(확정한 병원명 검색어), `focus`(관심 분야 ID, 예: `orthopedics`).
- 예: `https://예시도메인/?sido=11&focus=orthopedics` — 서울 + 정형외과 관심 분야.
- 화면에서 조건을 바꾸면 주소줄이 갱신되어 **북마크·공유**에 쓸 수 있습니다. (입력만 하고 검색하지 않은 글자는 URL에 넣지 않습니다.)

#### 지역 선택

1. 메인 페이지에서 **시도** 드롭다운을 클릭합니다.
2. 원하는 시도를 선택합니다 (예: 서울특별시).
3. **시군구** 드롭다운이 자동으로 활성화됩니다.
4. 원하는 시군구를 선택합니다 (예: 종로구).

#### 관심 분야 (선택)

- **안과의원**, **안과·눈 전문 병원급**, **정형외과**, **산부인과**(이름에 **여성병원** 등 포함 시 동일하게 추정), **소아과**, **척추·관절**, **성형외과**, **내과**, **신경과**, **이비인후과**, **피부과**, **비뇨의학과**, **치과** 중 하나를 고르면, 목록이 해당 성격에 맞게 **추정 필터**됩니다.
- 규칙은 **병원명**, 기관 **종별명**(안과의원·안과 병원급 구분 등), 공공데이터의 **진료과목 코드(`dgsbjtCd`)·진료과목명(`dgsbjtCdNm`)** 등을 조합합니다. 코드가 여러 개 붙어 있는 형식(예: `010305`)도 2자리씩 나누어 인식합니다. 실제 행정 분류·광고 표현과 다를 수 있으니 참고용으로 사용해 주세요.
- **척추·관절**은 이름에 척추·디스크 등이 없어도 **정형외과**(이름·진료과·코드 03)이면 포함합니다. 공공데이터에 과목이 비어 있어도 **진료과명**에 척추·디스크 등이 있거나, **마디·허리·좋은아침·굿모닝** 등 흔한 척추·관절 상호 표기가 있으면 포함합니다. 무릎·어깨만 전문인 곳도 섞일 수 있어 참고용입니다.
- **안과의원**은 이름에 **눈**(예: ○○눈의원)만 있어도 안과로 추정하되, **눈성형**·**안경** 등은 제외합니다. **이비인후과**는 **이목후**(구칭)·영문 **ENT** 표기도 포함합니다. **성형외과**는 **미용외과**·**미용+성형** 이름도 포함합니다. **산부인과**는 **산후**·진료과명에 산후 등, **소아과**는 **아동** 병원명도 포함합니다.
- **선택 안 함**이면 이 필터는 적용되지 않습니다.
- **추천 병원 보기**는 현재 화면에 보이는 목록(관심 분야 적용 후) 안에서만 후보를 고릅니다.
- 조건에 맞는 병원이 한 곳도 없으면 검색 결과 상단에 안내가 나오며, **관심 분야 선택 해제**로 전체 목록을 다시 볼 수 있습니다.

### 2. 병원 선택하기

검색 결과에서 비교하고 싶은 병원을 클릭합니다.

- 최대 **5개**까지 선택할 수 있습니다.
- 선택한 병원은 하단의 **비교하기** 바에 표시됩니다.
- 선택을 취소하려면 병원 카드의 체크박스를 다시 클릭하거나, 비교 바에서 X 버튼을 클릭합니다.

### 3. 비교하기

1. 병원을 선택한 후 하단의 **비교하기** 버튼을 클릭합니다.
2. 비교 페이지로 이동합니다.
3. 선택한 병원들의 비급여 가격이 테이블로 표시됩니다.

### 4. 비교 테이블 사용법

#### 필터 옵션

- **공통 항목**: 모든 병원에 공통으로 있는 항목만 표시
- **전체 항목**: 모든 항목 표시
- 공통 항목이 없을 때는 안내 문구를 확인하고 **전체 항목** 탭으로 전환하세요.

#### 정렬 옵션

- **인기순**: 많은 병원에서 제공하는 항목 우선
- **가격 내림차순**: 높은 가격부터 정렬
- **가격 차이순**: 병원 간 가격 차이가 큰 항목 우선
- **이름순**: 항목명 가나다순 정렬

#### 검색

- 검색창에 항목명 또는 코드를 입력하면 실시간으로 필터링됩니다.

#### 비용 시뮬레이터

- 각 항목의 **횟수**를 입력하면 병원별 **예상 총비용**이 자동 계산됩니다.
- 횟수 입력값은 브라우저에 저장되어 새로고침 후에도 유지됩니다.

#### 추천 병원 보기

- 검색 조건에 맞는 병원 중 점수 기반 추천 병원을 자동 선택할 수 있습니다.
- 추천 점수는 데이터 완전성, 항목 수, 평균가 안정성을 반영합니다.

#### 이상치 안내

- 평균 대비 일정 비율(기본 +30%) 이상 높은 가격은 **주의** 배지로 표시됩니다.
- 상단의 `주의 기준` 배지에서 기준을 확인할 수 있습니다.

#### 페이징

- 초기에는 상위 30개 항목만 표시됩니다.
- **더 보기** 버튼을 클릭하면 추가 30개씩 로드됩니다.

### 5. 가격 정보 이해하기

#### 가격 표시

- 각 병원의 가격이 **원** 단위로 표시됩니다.
- 평균 가격 대비 차이가 색상으로 표시됩니다:
  - 🔴 **빨간색**: 평균보다 높은 가격
  - 🔵 **파란색**: 평균보다 낮은 가격

#### 최고가/최저가 배지

- **최고가** 배지: 해당 항목의 최고 가격
- **최저가** 배지: 해당 항목의 최저 가격

#### 추가 정보

- **단위**: 회/일/건 등 항목의 단위
- **적용 기간**: 가격이 유효한 기간
- **상세 정보**: 클릭 시 해당 항목의 상세 정보 페이지로 이동

### 6. 모바일 사용법

모바일에서는 **스와이프 비교 뷰**를 사용할 수 있습니다:

1. 비교 페이지에서 좌우로 스와이프하여 다른 병원의 가격을 확인합니다.
2. 하단의 인디케이터로 현재 보고 있는 병원을 확인할 수 있습니다.
3. 인디케이터를 탭하여 특정 병원으로 바로 이동할 수 있습니다.

### 7. 자주 묻는 질문 (FAQ)

**Q: 가격 정보는 얼마나 최신인가요?**
A: 공공데이터포털의 최신 데이터를 기반으로 합니다. 각 항목의 적용 기간을 확인하세요.

**Q: 모든 병원의 모든 항목이 표시되나요?**
A: 각 병원에서 제공하는 비급여 항목만 표시됩니다. 병원마다 제공 항목이 다를 수 있습니다.

**Q: 병원에서 비급여를 고지해야 하는 것 아닌가요? 그런데 왜 여기에는 항목이 없나요?**
A: **의료기관이 환자에게 비급여 가격 등을 설명·고지해야 하는지**는 의료법령·고시 등에서 정하는 **기관의 의무**입니다. 이 사이트는 **건강보험심사평가원이 공공데이터포털을 통해 공개한 비급여진료비 API 결과**만 보여 줍니다. API에 등록되지 않았거나, 적용 기간이 지난 항목·금액 0원 처리 등으로 **서비스에서 걸러진 경우**, 또는 **일부 종별·기관에서 API 자체가 빈 목록**을 주는 경우에는 화면에 항목이 없을 수 있습니다. 실제 진료·수납 전 **해당 병원에 직접 확인**하는 것이 가장 정확합니다.

**Q: 가격이 정확한가요?**
A: 공공데이터포털의 공식 데이터를 기반으로 하며, 실제 진료 시 가격은 병원에 직접 문의하시기 바랍니다.

**Q: 비교할 수 있는 병원 수는 몇 개인가요?**
A: 최대 5개까지 비교할 수 있습니다.

### 8. 문제 해결

**검색 결과가 나오지 않아요**

- 지역·관심 분야·의료기관명 검색 조건을 확인하세요.
- 관심 분야를 **선택 안 함**으로 바꿔 전체 목록이 나오는지 확인해 보세요.

**비교 테이블이 표시되지 않아요**

- 병원을 최소 2개 이상 선택했는지 확인하세요.
- 네트워크 연결을 확인하세요.
- 페이지를 새로고침해보세요.

**가격 정보가 없어요**

- 심평원 공개 API에 해당 기관의 비급여 행이 없거나, 적용 기간 만료·0원 항목 제외 등으로 **화면에 남는 항목이 없을 수 있습니다**.
- 비교 페이지에서 **전체 항목** 탭과 **비급여 항목 0건 병원 자동 제외** 옵션을 확인해 보세요.
- 확정 가격·고지는 **해당 병원**에 문의하세요.
