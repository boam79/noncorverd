# Components

이 디렉토리는 재사용 가능한 UI 컴포넌트를 포함합니다.

## 예정된 컴포넌트

- `Layout/` - 레이아웃 컴포넌트 (Header, Footer, Container)
- `RegionSelector/` - 지역 선택 컴포넌트 (시도 → 시군구)
- `InstitutionFilter/` - 의료기관 종별 필터
- `HospitalCard/` - 병원 카드 컴포넌트
- `CompareBar/` - Floating Compare Bar
- `ComparisonTable/` - 비교 테이블 컴포넌트
- `Loading/` - 로딩 상태 UI
- `Error/` - 에러 상태 UI
